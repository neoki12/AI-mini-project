# 회귀 테스트용 쿼리 목록 — 4M 변경 영향 검토

4M 리뷰 경로의 정답(공장, 변경 유형, 등급, 필수 항목)은 `eval/4m_dataset.jsonl` 10건을 기준으로 한다.
아래는 도메인 전환 후 파이프라인이 끝까지 도는지 손으로 확인할 때 쓰는 질문이다.

| # | 쿼리 | 테스트 목적 |
|---|---|---|
| 1 | 의장 2라인(AS-2) 야간조 도어 트림 장착 공정에 신입 작업자 4명을 투입하려고 합니다. 4M 검토 부탁드립니다. | Man 단독 변경 — 같은 라인의 무관한 교정 만료 설비(AS-NR-120)가 조사되는지 |
| 2 | 프레스 1라인 후드 외판 드로잉 금형(PR-DIE-HD01)을 수정하려고 합니다. 4M 영향 검토 부탁드립니다. | Machine — 프레스 공정 표준·검사 기준 조회 |
| 3 | 루프 패널용 강판의 공급사를 기존 X제철에서 Y제철로 변경합니다. 재질과 두께 사양은 동일합니다. 검토해주세요. | 공장명 미언급 — 키워드(강판)로 프레스 판별 |
| 4 | 차체 대시 패널 라인 용접 로봇(BD-RB-301, BD-RB-302)의 용접 전류 조건을 변경합니다. 필요한 검증 항목을 알려주세요. | 설비 2대 병렬 조회 + 첫 Tool 호출 재시도(Wave 9) + 이상 상태 설비 |
| 5 | 차체 플로어 라인(BD-FLOOR)에 신규 용접 지그를 도입하고, 같은 시점에 구조용 접착제를 B사 제품으로 변경합니다. 이번 주말에 적용할 예정입니다. | 복합 변경(Machine + Material) + 가동 중 라인 |
| 6 | 협력사로부터 브레이크 호스 브래킷 부품의 4M 변경 신고(생산 공장 이전)가 접수됐습니다. 의장 공장 기준으로 검토해주세요. | 안전 체결부 — 의장 공정 표준 조항 2, 3 조회 |
| 7 | 안녕, 너는 누구야? | route=chat 직행(Wave 5) — 토큰 스트리밍(AnswerToken) |
| 8 | 제 이름은 민수입니다 → (다음 메시지로) 제 이름이 뭐였죠? | Wave 12 세션 기억 — 서버 재시작 후에도 유지되는지 |
